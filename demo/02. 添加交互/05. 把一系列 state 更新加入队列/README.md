# 把一系列 state 更新加入队列

设置组件 state 会把一次重新渲染加入队列。但有时你可能会希望在下次渲染加入队列之前对 state 的值执行多次操作。为此，了解 React 如何批量更新 state 会很有帮助。

## 启动

```bash
npm install
npm run dev
```

## Demo 说明

### 批处理

React 会等到事件处理函数中的**所有**代码都运行完毕再处理 state 更新。即使调用了三次 `setNumber(number + 1)`，由于每次渲染中 `number` 的值是固定的，三次调用都等同于 `setNumber(1)`，最终结果只会 +1。

```jsx
setNumber(number + 1); // 0 + 1
setNumber(number + 1); // 0 + 1
setNumber(number + 1); // 0 + 1
```

| 更新队列 | n | 返回值 |
|---------|---|-------|
| "替换为 1" | 0（未使用） | 1 |
| "替换为 1" | 1（未使用） | 1 |
| "替换为 1" | 1（未使用） | 1 |

最终结果为 `1`。

### 更新函数

使用更新函数 `n => n + 1` 代替 `number + 1`，React 会将每个更新函数加入队列，依次执行，前一个的返回值作为下一个的参数：

```jsx
setNumber(n => n + 1);
setNumber(n => n + 1);
setNumber(n => n + 1);
```

| 更新队列 | n | 返回值 |
|---------|---|-------|
| `n => n + 1` | 0 | 0 + 1 = 1 |
| `n => n + 1` | 1 | 1 + 1 = 2 |
| `n => n + 1` | 2 | 2 + 1 = 3 |

最终结果为 `3`，点击"+3"按钮正确递增三次。

### 替换后更新

先替换 state 再使用更新函数：

```jsx
setNumber(number + 5);   // "替换为 5"
setNumber(n => n + 1);   // 更新函数
```

| 更新队列 | n | 返回值 |
|---------|---|-------|
| "替换为 5" | 0（未使用） | 5 |
| `n => n + 1` | 5 | 5 + 1 = 6 |

最终结果为 `6`。`setState(x)` 实际上会像 `setState(n => x)` 一样运行，只是没有使用 `n`。

### 更新后替换

更新函数后再替换 state，最后的替换操作覆盖之前所有计算：

```jsx
setNumber(number + 5);   // "替换为 5"
setNumber(n => n + 1);   // 更新函数
setNumber(42);            // "替换为 42"
```

| 更新队列 | n | 返回值 |
|---------|---|-------|
| "替换为 5" | 0（未使用） | 5 |
| `n => n + 1` | 5 | 5 + 1 = 6 |
| "替换为 42" | 6（未使用） | 42 |

最终结果为 `42`。

## 摘要

- 设置 state 不会更改现有渲染中的变量，但会请求一次新的渲染
- React 会在事件处理函数执行完成之后处理 state 更新，这被称为**批处理**
- 要在一个事件中多次更新某些 state，可以使用 `setNumber(n => n + 1)` 更新函数
- **更新函数**会被加入队列依次执行；**其他值**会导致"替换为该值"被加入队列
